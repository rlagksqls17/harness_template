prompt_agent_dev 실제 실행 구조

이 문서는 2026-09-03 r28의 현재 구조와 로컬 Proteomics fixture 검증 결과만 설명한다.

실행 순서

Prompt
자연어를 TaskSpec으로 만들고 분배한다. 직접 업무는 수행하지 않는다.
Passive
프로젝트의 direction·dev_env 등 필요한 기록을 실제 조회해 반환한다.
Active
선택된 job Agent가 별도 process에서 준비·진행·검증·완료 증거를 반환한다.
Supervisor
마지막 별도 process에서 순서·증거·안전 규칙을 확인한다.

실제 업무 진입점은 python src/harness.py execute다. route는 선택만 하며 실행 증거가 아니다.

완료 Gate

  • 각 단계에는 고유 invocation ID와 process ID, 시작·종료, 입력·출력 digest, 상태가 필요하다.
  • Active는 네 stage의 증거를 모두 반환해야 한다.
  • Supervisor 점수 90 미만 또는 단계 누락 시 완료 보고를 차단하고 1회 권한을 폐기한다.
  • 성공한 pre-output gate만 권한을 소진하며 최종 상태는 다시 INVALID다.

최우선 안전 규칙

서버는 항상 읽기 전용이며 쓰기·동기화·업로드·프로세스·컨테이너·권한 변경을 금지한다.
인터넷은 GitHub만 허용하며 다른 웹·API·패키지 저장소 접근을 차단한다.
